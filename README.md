
# PortScannerV1 🛡️

A custom, lightweight, and fast network port scanner built with C# and WPF.

Designed with a focus on defensive security and blue team operations, this tool allows security analysts and network administrators to quickly discover open ports and active services on target systems. Originally developed as a Windows Forms application, the project was completely migrated to WPF to provide a modern, responsive, and user-friendly interface.

## ✨ Features
* **Rapid Port Scanning:** Efficient and reliable scanning mechanism for identifying open network ports.
* **Modern WPF Interface:** Clean and intuitive UI, offering a significantly improved user experience over traditional WinForms.
* **Target Customization:** Scan specific IPs, subnets, and custom port ranges.
* **Defensive Security Focus:** Built to assist in network mapping, vulnerability assessment, and securing network perimeters.

## 🛠️ Technologies & Tools
* **Language:** C#
* **Framework:** .NET / WPF (Windows Presentation Foundation)
* **Networking:** `System.Net.Sockets`

## 🚀 Getting Started

### Prerequisites
* Visual Studio 2022 (or later)
* .NET 8.0 SDK

### Installation
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/mehtappamuk05/PortScannerV1.git
   ```

2. Open `PortScannerV1.sln` in Visual Studio.
3. Restore any required NuGet packages.
4. Build and run the project (Press `F5`).

## 💡 Usage

1. Launch the application.
2. Enter the target IP address in the designated field.
3. Specify the port range you want to scan.
4. Click the "Scan" button and monitor the real-time results on the dashboard.
